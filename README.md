# Unimind Studios website

The finished website for www.unimindstudios.com. Plain HTML, CSS and JavaScript; no build step needed.

- `index.html` is the home page; every other page is a folder with its own `index.html`.
- `.htaccess` holds the server settings for Hostinger (https + www redirect, 404 page, caching, compression).

Hostinger: deploy this repository, branch `main`, root directory `./`.
